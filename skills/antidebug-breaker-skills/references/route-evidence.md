# 路由结果、加载方案与来源

目标是发现并定位用户关心的 Vue/React 隐藏动态路由，并交付下述加载方案。可分析源码、运行时、懒加载资源、接口数据或组合使用其他办法，不要求先运行插件，也不规定固定的分析步骤。

## 可核查的结果

报告以路由和来源为主体；下面是可用字段，不要求固定表格或额外文件格式：

| 信息 | 内容 |
| --- | --- |
| 路由 | 完整路径或保留参数的模式，例如 `/users/:id`；必要时标明父路由、别名、basename/hash 前缀 |
| 来源 | JS URL/文件，配合函数、行列、模块 ID 或可检索片段；source map 位置应与生成文件位置区分 |
| 证据状态 | 路由定义、静态候选、运行时已注册、已验证访问等实际获得的证据；不强制为所有条目补齐所有状态 |
| 插件对比 | 基线中已存在、基线中未捕获，或未对比 |
| 条件 | 已知的角色、功能开关、懒加载、菜单接口、注册时机等；未知时如实说明 |

路径去重时保留不同来源、实例和条件。嵌套路由按真实路由语义组合，不能把绝对子路径错误拼到父路径后；保留动态参数和通配符，不猜出一批具体页面。

有些动态路由由接口下发，再由 JS 拼接或注册。此时同时标出数据来源接口与负责转换/注册的 JS；若无法定位某部分，说明未知。内联脚本或 eval 源按实际来源记录，不为满足“哪个 JS”而虚构文件。

菜单链接、组件名、文件路径或任意字符串可作为线索，但不能直接当成已注册路由。仅返回 SPA 外壳的 HTTP 200、绕过前端跳转或手动注册路由，也不证明原始页面已注册该路由或后端允许其数据访问。

## “插件未捕获”的含义

差异基线可以来自本次插件输出、用户提供的导出或先前记录；记录足以解释差异的页面、登录/角色状态、采集时点和有效性。比较时区分页面已加载的原始路由与本次修改/补注册后才出现的路由。

采集状态正常、未过期且目标页面/状态可确认的空快照（`routes: []`），可以作为本次未捕获的比较基线，但不能证明全站不存在路由。未开启采集脚本、超时、内容脚本不可用或缓存过期得到的空结果，不能视为有效空快照。无法确认有效性时标为对比条件不足；没有可用基线时继续收集并交付来源，说明未与插件比较。

“插件未捕获”只描述相对本次基线的差异，并不自动证明插件缺陷。未加载资源、角色不同、接口未下发、动态注册未触发都可能导致差异。最终范围对应已检查的资源和状态，避免承诺找全网站所有角色、所有版本的路由。

## Vue/React 隐藏路由的加载交付

1. **首选：自动加载的 Hook 脚本。** 提供完整源码文件，说明目标匹配范围、安装或注入方法、运行时机和所需依赖。脚本应在所说明的运行条件下自动完成目标路由所需的注册或加载，并使用真实的路由定义及对应组件、懒加载资源；不能只打印路由列表，或依赖 Agent 每次临时求值才生效。运行环境自主选择，不强制油猴或本插件。使用脚本库时同样遵守本技能中复用脚本 ID、保留最终交付及清理本次实验脚本的要求。

2. **Hook 确实无法可靠实现时：浏览器替换 JS。** 说明 Hook 的具体限制，交付实际修改后的 JS 文件或可应用补丁，准确标出待替换的 JS URL/文件、原版本或修改位置的定位依据。给出补丁应用方法（如适用）、浏览器中所用替换工具的设置与操作步骤，以及刷新验证、确认替换生效和恢复原文件的方法。不能只建议用户“修改路由表”或“用浏览器替换 JS”，也不能只交付仍需用户补写关键逻辑的模板。

交付验证应来自最终 Hook 或替换文件在所说明的环境中的实际运行。确认目标路由能够被应用解析、对应的真实页面组件能够加载，说明已验证的路由、使用条件和仍受限制的部分；新增占位路由、只取消导航跳转或取得 HTTP 200 不算加载完成。区分原应用已注册的路由与本次补注册或修改后才出现的路由；前端页面加载不代表后端接口已授权或业务数据可访问。无法完成任一种方案时如实标为未完成，并说明具体阻塞，不以未经验证的脚本或替换建议代替已实现的加载方案。

## 可借鉴的线索

用户提供的《最大化获取Vue框架SPA类型下的路由》（2025-10-09，0xsdeo）强调已注册路由与尚未加载/添加路由的差异、多个应用/路由实例，以及前端导航守卫与路由定义的区别。源码中未执行的路由表、动态导入、注册调用、接口返回的路由/菜单数据都可能提供补充证据，自行判断哪些值得分析。

文章中的 `addRoute`、构造路由器时补充路由、替换 JS、修改白名单等是特定场景的手段，不规定定位与取证的路线；最终成果仍须满足上面的加载交付要求。清除导航守卫可能同时阻止动态路由注册或初始化；停掉跳转并不使未加载路由自动出现。

Vue 与 React 的可用结构取决于实际框架/路由器与版本。不要把 Vue 的实例方法套到 React，也不要把 React Fiber 或菜单候选等同于完整路由表。React 的 Hook 或替换文件须适配目标实际使用的路由库、版本与加载机制，区分组件懒加载和路由定义后加载，不假定所有 React 应用都有统一的路由注册接口。
