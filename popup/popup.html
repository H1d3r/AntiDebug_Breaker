反Hook检测
开启反Hook检测功能后，可以反制一些常见的Hook检测手段。例如如果打开某个脚本后并未实现功能就可以尝试开启本脚本。 注意：本脚本目前尚未成熟，可能存在一些未知的bug，请谨慎使用。
标准模式
开启标准模式/全局模式 标准模式：插件默认模式，当勾选脚本并刷新网站后，脚本仅会注入到当前网站。 全局模式：当开启全局模式后，勾选的脚本将注入到每个网站中。 注：对于通过file://协议或localhost访问的页面，需要完成以下操作后才能注入脚本：1. 开启全局模式2. 打开 chrome://extensions/ 3. 找到 AntiDebug_Breaker，点击「详情」 4. 开启「允许访问文件网址」

必看说明
1. 本板块分三类脚本：固定变量脚本、非固定变量脚本、非固定变量+可检索关键字脚本。 2. 固定变量脚本默认提供一个固定值，修改固定值后需按Enter保存。 3. 非固定变量+可检索关键字脚本开启后，未开启检索关键字功能时会输出所有Hook到的内容；如果开启检索关键字并且设置了关键字仅会Hook输出关键字内容；若开启检索关键字功能但并没有设置关键字时将会输出所有Hook到的内容。 4. 可检索关键字的功能采取的是模糊检索，也就是说只要传进的内容中包含了检索的关键字就能被hook到。 5. 开启debugger或stack功能后，如果hook到内容将会触发debugger或打印堆栈信息。 6. 如果下方没有要用的hook脚本可以提issues，也可以联系我(公众号：Spade sec)，我会考虑是否纳入到后续更新进程中。

    首次连接说明

    配套包包含安装说明。

    1. 点击“下载 MCP + Skills”，在打开的 GitHub 发布页的 Assets 中下载 AntiDebug_Breaker-Agent-*.zip。解压后按包内安装说明操作：在 mcp 目录执行 npm ci 和 npm run setup，再将 Skills 安装到客户端。
    2. 将本项目 MCP 加入你的 Agent 客户端配置，由客户端启动服务；也可先执行 npm start 检查扩展连接。
    3. 粘贴配对信息，点击“启用 MCP 并允许 Agent 控制浏览器”，一次开启连接和控制。设置会保存，正常重启后无需再次启用。
    4. Agent 通过扩展连接标签页，可使用脚本开关、Hook 参数、路由、断点、网络和页面交互，无需开启 Chrome 的远程调试连接。
    5. 启用后，主按钮变为“保存连接设置”，可更新地址和密钥。“停止 MCP”会断开连接和调试会话，并保留已保存的配对信息。
    6. 通过 Chrome 调试提示条取消后，MCP 连接保持启用；需点击“重新启用浏览器控制”才能恢复控制，点击时也会保存当前配对信息。
    7. Agent 可管理脚本库，用户也可在 Scripts 板块编辑名称、匹配网站和源码，以及启停或删除已有脚本。首次使用请在 Chrome 扩展详情页开启“允许用户脚本”（Chrome 120–137 使用“开发者模式”）。已启用的脚本会在匹配网站加载时自动注入；停止 MCP 不会停用这些脚本。可关闭“允许用户脚本”以停止后续注入，再刷新页面清除旧脚本影响。
    8. 旧版设置会保留，已停用的控制不会因升级或重新打开面板而开启。若 Chrome 在更新后停用扩展，请先到扩展管理页确认新增权限。

    调试数据会交给你选择的 Agent 客户端。Chrome 的调试提示条无需点击允许；停止 MCP 不会撤销扩展已声明的 Chrome 调试权限。
